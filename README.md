# Python + SQL Quiz

Quiz didattico a **pagina singola**, in italiano: 60 domande a risposta multipla, 30 di Python e 30 di SQL.
Nessuna dipendenza, nessun build, nessuna connessione richiesta — basta aprire `quiz.html` nel browser.

## Caratteristiche

- **60 domande** con opzioni e ordine mescolati a ogni partita
- Spiegazione dettagliata di **ogni** risposta, con concetto, esempio di codice eseguibile e **link alla fonte ufficiale**
- Tre modalità: misto completo, solo Python, solo SQL
- Tema chiaro/scuro, evidenziazione della sintassi, punteggio con serie di risposte esatte e record salvato in locale
- Schermata finale con risultato per linguaggio e ripasso degli errori
- Navigazione da tastiera: `1`–`4` o `A`–`D` per scegliere, `Invio` per verificare e avanzare, `T` per il tema

## Fonti

- **Python** — documentazione ufficiale [docs.python.org/3](https://docs.python.org/3/) (versione stabile 3.14.7)
- **SQL** — non esiste uno "SQL 2026": l'ultima edizione ISO è **SQL:2023** (ISO/IEC 9075:2023), in 11 parti.
  Ogni domanda SQL cita la parte dello standard più una pagina pubblica di riscontro, per lo più
  [PostgreSQL 18](https://www.postgresql.org/docs/current/features.html), che dichiara conformità a 170 delle
  177 funzionalità Core di SQL:2023.

Dove una funzionalità è un'estensione di un singolo motore e non standard (per esempio `MATERIALIZED VIEW`,
`LIMIT`, `==`), la domanda lo dice esplicitamente.

## Uso

Apri `quiz.html` con un doppio clic, oppure visita la versione pubblicata su GitHub Pages.
